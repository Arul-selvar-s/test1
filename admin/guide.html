Blog Help Guide

For the person who looks after the Elysian Dental Lounge website. No coding is needed for anything on this page.

Open the blog editor See blog status

1. How it works, in four lines

You write an article in the blog editor and press save. A few minutes later the website shows it on the Blog page, on its own page, and in the Latest articles section of the homepage (the 2 newest), and on the page of any treatment you choose as its related treatment. Nothing else to upload or edit. The Blog status page lists every article and says in plain English if one is not showing, and why.

2. First time only: signing in

The editor uses a GitHub account (GitHub is where the website files are kept). There is no separate password for the website; you sign in with a one-time “access token”, which is like a long password made just for this editor.

  1. Owner gives you access. The person who owns the GitHub project adds your GitHub account as a collaborator with Write access (GitHub → the project → Settings → Collaborators). You must accept the invitation email.
  2. Make your token. On GitHub click your picture → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
    • Name: Blog editor
    • Expiration: pick the longest offered (note the date in your calendar; see “Token expired” below).
    • Repository access: Only select repositories → choose test1.
    • Permissions → Repository permissions → Contents: Read and write. Leave everything else alone.
    • Press Generate token and copy it (you only see it once).
  3. Open the blog editor, press Sign In with Token, paste the token, and continue.
Keep the token private like a password. Only sign in on your own computer or phone. If you ever lose it or think someone saw it, delete it on GitHub (same Settings page) and make a new one; nothing on the website breaks.

3. Writing and publishing an article

  1. In the editor choose Blog articles → New Blog article.
  2. Fill in the boxes (see the table below).
  3. When it is ready switch Show on website ON, then press Save (top right).
  4. Wait 2 to 4 minutes, then open the website and refresh (Ctrl+F5 on a computer). If it is not there, open Blog status: it will say why.

Change, hide or delete an article

  • Change: open it in the editor, edit, press Save. The page updates in a few minutes.
  • Hide for now: switch Show on website OFF and Save. It disappears from the website but you keep the text.
  • Delete: open it and use the Delete option in the editor. Its page is removed automatically. (Anyone who saved the old link will see a “not found” page.)

5. When you connect your own domain name (for example elysiandental.com)

The blog needs no changes. The editor, the blog pages, the sitemap and the Google information all pick up the new address by themselves.

  1. On GitHub: the project → Settings → Pages → Custom domain. Type the domain and Save. GitHub shows the DNS records to add at the company where you bought the domain; add them there and tick Enforce HTTPS when it becomes available.
  2. GitHub adds a file called CNAME to the project. The next automatic build reads it. To do this straight away: Actions → Build blog → Run workflow.
  3. The editor now lives at your-domain/admin/. Sign in with your token again once on the new address (the token itself still works).
  4. In Web3Forms, add the new domain if your key is restricted to certain websites.
  5. In Google Search Console add the new site and submit your-domain/sitemap.xml. Update the website link on your Google Business Profile.

Pages that were made before the domain was connected may be saved by Google under the old github.io address for a while; this sorts itself out.

6. Good habits

  • Write for patients in simple language. Do not promise results or compare with other clinics; check claims against Dental Council advertising rules.
  • Do not put patient names, photos or medical details in articles without written consent.
  • Use the editor for blog work only. Do not rename or delete files directly on GitHub unless your web developer asks you to.
  • Bookmark this guide and the Blog status page.
